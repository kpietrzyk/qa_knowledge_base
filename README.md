# QA Knowledge Base

Praktyczna baza wiedzy o narzędziach QA, szczególnie dla **manualnego testera aplikacji mobilnych**, który chce wejść w automatyzację i rozsądnie używać AI.

📖 **[Otwórz pełną dokumentację →](https://kpietrzyk.github.io/qa_knowledge_base/)**

- **[Słownik](docs/GLOSSARY.md)** — terminy QA dla juniorów
- **[Narzędzia](docs/tools/)** — opisy 50+ narzędzi wg kategorii (mobile, API, web, AI, debugging, test management, bug reporting, UI inspection)
- **[Workflows](docs/workflows/)** — gotowe procesy krok po kroku
- **[Prompty AI](docs/prompts/)** — gotowe prompty do codziennej pracy testera
- **[Checklisty](docs/checklists/)** i **[szablony](docs/templates/)**

- **[Źródła i weryfikacja](docs/SOURCES.md)** — konta i newslettery do śledzenia aktualizacji narzędzi

## Dla kogo

- manualnych testerów aplikacji mobilnych (Android / iOS)
- testerów webowych (panele admin, PWA, webview)
- juniorów i mid-level QA budujących portfolio
- testerów, którzy chcą rozsądnie używać AI zamiast bezmyślnie kopiować odpowiedzi
